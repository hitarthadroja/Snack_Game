# Snack_Game

📌 Project Description

This project is a classic Snake Game implemented using Java AWT (Abstract Window Toolkit).
It demonstrates real-time gameplay using keyboard input, multithreading, and graphics rendering.

🎮 Game Features : 
<br><br>
AWT-based graphical window

Keyboard arrow key controls

Smooth snake movement using threads

Random food generation

Score tracking system

Collision detection (wall & self)

Game over screen display
<br><br>

🧠 Concepts Used :
<br><br>
Java AWT (Frame, Graphics, Color)

Event handling with KeyListener

Multithreading using Runnable and Thread

Arrays for snake body management

Random number generation

Object-Oriented Programming (OOP)
<br><br>
🕹️ Controls :
<br>
⬅️ Left Arrow – Move Left
➡️ Right Arrow – Move Right
⬆️ Up Arrow – Move Up
⬇️ Down Arrow – Move Down
<br><br>
